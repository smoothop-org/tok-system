# publications/tok_1

The **tôk 1** publication of the tôk system (`tok_1.tex`), its figures, and its
companion scripts.

This folder was generated from the `stokex` ($tôkEx) environment. The scaffold —
preamble, Smoothop branding, figure pipeline and compilation — is wired and
proven; the **content of the publication remains to be written** (the document is
a skeleton with `\placeholder{...}` blocks).

## What the folder contains

| Path | Role |
|---|---|
| `latex_document/tok_1.tex` / `.pdf` | the document (skeleton for now) |
| `figures/gen_figures.py` | generates the PDF figures of the document |
| `figures/tok_1_example.pdf` | placeholder figure, regenerated by the script |
| `figures/smoothop_logo.pdf` | title-page logo (hand-made asset, not script-generated) |
| `tok_1_go_live.md` | internal go-live checklist (working file) |

## Python environment (local, permanent, **never pushed**)

The figures are generated by `gen_figures.py` (matplotlib, text rendering via
system LaTeX). The environment lives in a single `.venv/` at the **repo root**
that is **local and gitignored**: it is shared by every instance of Milu on the
machine, but never leaves for GitHub. Only `requirements.txt` — the *recipe*, at
the repo root — is versioned. Never create a second `.venv` (see AGENTS.md).

## Generating the figures

```sh
./.venv/bin/python publications/tok_1/figures/gen_figures.py
```

Writes the PDFs into `publications/tok_1/figures/` (the script's own directory,
independent of the current working directory). The logo
(`smoothop_logo.pdf`) is **not** produced by the script — it is a hand-made asset.

## Compiling the document

Simple one-shot build, from the document's directory:

```sh
cd publications/tok_1/latex_document
latexmk -pdf -interaction=nonstopmode -halt-on-error tok_1.tex
```

Continuous build — the **auto compile** recipe defined in AGENTS.md; it keeps
latexmk running and rebuilds on every save of the `.tex`, with no viewer:

```sh
cd publications/tok_1/latex_document
latexmk -pdf -pvc -view=none -interaction=nonstopmode -halt-on-error tok_1.tex
```

It runs until stopped (Ctrl-C). `latexmk` handles the multiple passes
(cross-references) on its own. The build artifacts (`.aux`, `.log`, `.fls`,
`.fdb_latexmk`, `.out`, …) are gitignored by the repo-root `.gitignore`.

## Placeholders and go-live

The document uses a `\placeholder{...}` macro (yellow box) to mark what remains
to be filled in, and skeleton macros `\placeholdertitle` / `\placeholdermonth`
for the title and date. The go-live checklist is in `tok_1_go_live.md`.

Before tagging/submitting:

```sh
grep -n "placeholder\|TO BE FILLED\|Month 2026" latex_document/tok_1.tex
```

must return nothing in the body of the text.
